# Experiment 02 — Four-Bit R-2R DAC

**Status:** Planned

## Objective
Design an R-2R resistor ladder and compare output voltage with theoretical values for all 16 input codes.

## Planned steps
1. Document reference voltage, R and 2R values, and output polarity.
2. Draw the switch configuration and the full resistor ladder in LTspice.
3. Sweep all 16 binary input combinations.
4. Record predicted and simulated voltages.
5. Calculate step size and compare errors.
6. Explore loading and resistor tolerance.

## Evidence
Original LTspice schematic, output waveform, data table and a report of expected versus actual behavior.
